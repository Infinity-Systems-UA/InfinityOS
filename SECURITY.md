# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| xx102026   | ✅ (Fully supported)       |
| xx092026   | ⚠️ (May not support new app releases)     |
| < 01092026   | ❌ (Not recommended)     |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately through "GitHub's private vulnerability reporting" (../../security/advisories/new).

Please do not disclose unpatched vulnerabilities publicly.

Include the following information in your report:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Any relevant logs or proof of concept.

We will acknowledge reports as soon as reasonably possible, investigate the issue, and inform you of the outcome. If the vulnerability is confirmed, we will work on a fix and coordinate disclosure where appropriate.
